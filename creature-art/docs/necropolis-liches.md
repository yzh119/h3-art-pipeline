# Lich and Power Lich animation workflow

The generated textured Lich replaces the rejected primitive hat/armour study.
Power Lich has a separate generated mesh with a crowned helmet, black orb in a
crescent fitting, and a long chainmail skirt. Both retain the original left-hand
staff carriage. The accepted Wight export is unchanged.

## Sources and authoring

Durable source directories under `~/vcmi-art/necropolis-roster/`:

- `lich-bootstrap-01`: concept, Meshy7 mesh, automatic rig and request metadata.
- `power-lich-bootstrap-01`: separate concept, Meshy7 mesh and automatic rig.
- `lich-motion-full-01` / `power-lich-motion-full-01`: packed editable scenes,
  native exports, script snapshots and source/reference hashes.

Each mesh request consumed 30 credits; each automatic rig consumed 5. The base
Lich mesh's 30 credits were already reported in the bootstrap article. New spend
in this stage is 40 credits: its rig plus the Power Lich mesh and rig. Local
Blender work does not invoke Meshy animation generation.

`rig_mesh.py` persists paid task IDs before polling and supports `--resume` without
resubmitting. `lich_study.py` rebuilds imported bone tails from anatomical joint
heads, retains textured body geometry/weights, and removes the extra imported
Icosphere. It measures the shaft in an unobstructed height band, extracts a rigid
staff, and attaches it to the anatomical LEFT hand. Power Lich's upper crescent
and orb need a wider extraction region than the shaft. Nearby grip vertices are
rigidly weighted to the hand.

Leg reach is solved from actual two-bone lengths before moving the hips. Wrist
targets are limited to the reachable sphere, with corrections above 0.08 model
units rejected. This is a small target adjustment, not stretching the arm.

The original `CLICH.DEF` / `CPLICH.DEF` supply group counts: each has 16 used groups
and 116 frames per scale. Duplicate unused turn groups 9/10 are omitted by the
same shared group mapping as earlier exports. Each of the three ranged groups
has 11 frames. Native canvas remains 450x400 (900x800 at 2x).

Walking holds the staff upright; melee tips it near horizontal; ranged attacks
have a distinct angle and a short red textured-emission pulse. Death folds
forward and settles against evaluated mesh vertices. It retains an intact body,
so it differs from the original's disintegrating heap. No cloth simulation or
ragdoll is claimed. Turns use independent halves around the engine facing flip.

## Verification and limitations

Every editable scene is reopened before sampling integer and half frames. Each
unit has 880 saved samples, including 73 death samples. Checks cover IK endpoint
error, staff socket attachment and death-floor contact. Native output frames also
require nonempty alpha and unclipped bounds. These checks do not exhaustively
validate skin intersections, chainmail contact or native battle timing.

Camera calibration is performed once on holding; no per-animation recentering.
Lich's raster height may end one pixel above the requested 182 due to alternating
raster bounds. Power Lich targets 210. Both retain the existing showcase canvas
registration. Prebaked effects are generated by `roster_mod.py`, without changing
engine source or ranged damage/projectile configuration.

## Failed attempts retained

- `lich-motion-probe-01`: straight legs could not reach the displaced walking
  target; frame-one endpoint error was 0.022439. Lowering the hips from measured
  limb reach fixed it.
- `lich-motion-probe-02`: melee and ranged poses were nearly identical and death
  fell backward with raised knees. This preview is superseded.
- `lich-motion-check-03`: downward shooting exceeded left-arm reach by enough to
  produce 0.011859 endpoint error. A bounded reach projection fixes it; checks
  were not weakened.
- `lich-motion-probe-03` / `power-lich-motion-probe-01`: the intended red emission
  instead brightened the original texture because a texture connection overrode
  the default colour. The final shader explicitly replaces that connection with
  a texture-times-red node, preserving texture detail.
- Power Lich's first check exited before authoring because its native reference
  uses `powerLich`, while the CLI variant is `power-lich`; the explicit mapping
  corrects that mismatch.

Blog figures must preserve historical failures with clear captions and regenerate
current examples from the final outputs. Offline videos use 4 fps holding / 8 fps
other groups for review; these are not runtime timing measurements or screenshots.

## Reproduce an export

Use a fresh directory for every run. Blender is fixed to four render threads and
32 samples, with deterministic render seeds. `--no-render` still saves and
reopens all clips for checks; its manifest is marked incomplete for packaging.

```sh
blender -b --python-exit-code 1 --python creature-art/lich_study.py -- \
  --model ~/vcmi-art/necropolis-roster/lich-bootstrap-01/rigged.glb \
  --out ~/vcmi-art/necropolis-roster/lich-motion-new \
  --references ~/vcmi-art/necropolis-roster/reference-01/manifest.json
```

For the upgrade, use its `power-lich-bootstrap-01/rigged.glb` and add
`--variant power-lich`. Do not edit the authoring script while either render is
running. The `code/` directory records the exact scripts used by each export.
